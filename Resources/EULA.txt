Gatekeeper
----------
This build is ad-hoc signed and not notarized. On first launch macOS may block
it. Open System Settings → Privacy & Security → "Open Anyway", or run:
  xattr -dr com.apple.quarantine /Applications/Drift.app
Only do this for a build you obtained from Drift's official GitHub Releases.
